# Tic Tac Toe

Atividade da matérias de **PIU**

## Como executar

1. **Clone e acesso o repositório**

    ```bash
    git clone https://github.com/Davi-1903/Tic-Tac-Toe.git
    cd Tic-Tac-Toe
    ```

2. **Instale as dependências**

    ```bash
    npm install
    ```

3. **Execute a aplicação**

    ```bash
    npm run dev
    ```

Se tudo ocorrer bem, a aplicação está rodando em [http://localhost:3000](http://localhost:3000)
